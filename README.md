# STRATHVISION

Athletic Visual Analysis Tool

Local-first dual-video analysis workstation with pack-driven style matching against private coach/mentor profiles.

## Status

Architecture and contracts are defined. Implementation has not started.

## Core Documents

- [ARCHITECTURE.md](docs/ARCHITECTURE.md) — System boundaries and design invariants
- [INTERFACES.md](docs/INTERFACES.md) — Exact contracts (no implementation)
- [EXECUTION_PLAN.md](docs/EXECUTION_PLAN.md) — Ordered, gated tasks for implementation

## Non-Goals (v1)

- Required accounts or cloud storage
- Public coach marketplace or social features
- Free-form AI coaching chat
- Generic multi-sport engine without packs
- Live multi-cam cloud streaming
