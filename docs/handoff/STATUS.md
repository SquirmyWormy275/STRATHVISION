## Blockers / questions for the human

- **Pick a local speech transcriber** for voice notes (for example whisper.cpp). Until then, voice notes are saved without spoken labels.
- **The Gurr experiment** (CARNE_ASADA.md "Experiment Integration") needs the Matthew and Daniel Gurr race and training footage, plus a real 3D pose model and implement tracker. The stand-in pose makes any results meaningless.

- **The adapter compiler needs an Anthropic API key on the workbench.** Set `ANTHROPIC_API_KEY`. The default model is `claude-opus-5-5`. The provider and model are a human decision the docs don't make, so confirm or change them. The compile path is unit-tested against the Messages API request and response shape but has not been run live here.

- **Review the timber pack v1** (`apps/strathvision/assets/packs/timber.json`): phases, metrics, weights, attribute names. It is an initial catalog written without a coach. Also review the probe interpretations in DECISIONS.md Phase 6.

- **Confirm the profile-gate defaults** (not blocking; they are pack-overridable): `min_critical_pose_confidence` 0.6 and `self_consistency_threshold` 0.5. Without a per-metric `min_spread`, leave-one-out scores sit around 0.6–0.7 for most footage (DECISIONS.md, Phase 4). Real packs should set `min_spread` per metric.

- **Which 3D pose model?** (needed before real footage gives real metrics, not before Phase 4's synthetic-clip acceptance.) DECISIONS.md requires full-body 3D root-relative pose and a lightweight implement tracker, but doesn't name the models. The engine has `PoseEstimator` / `ImplementTracker` interfaces ready. The human must pick the models and confirm their licences.

- **Phase 1 Windows acceptance is open.** On a Windows PC: `cd apps/strathvision && flutter run -d windows`, then follow the "Phase 1 manual check" in apps/strathvision/README.md. iOS/macOS builds need a Mac.
