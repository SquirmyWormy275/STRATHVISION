# Learn STRATHVISION

Start with the [project overview](../../README.md) and [five-step review walkthrough](../GETTING_STARTED.md). The core product is usable video review; model outputs are experimental additions.

## Suggested learning sequence

1. [Dual-video workspace](Dual-Video-Workspace.md): understand sync and saved review before analysis.
2. [Architecture](../ARCHITECTURE.md): trace video through Flutter, local pose, Dart metrics and a profile package.
3. [Packs](Packs.md): see how an event defines phases, metrics and weights.
4. [Profiles and gates](Profiles.md): learn what a ready profile proves and what it does not.
5. [Style matching](Style-Matching.md): inspect a score and its ranked differences.
6. [Design decisions](Design-Decisions.md) and [local-first constraints](Local-First.md): understand the tradeoffs.
7. [Local datasets](../DATASETS.md): inventory originals and guard session splits before fitting.
8. [Research results](../RESEARCH_STATUS.md): compare reproducible studies, failures and limits.
9. [Validation](../VALIDATION.md) and [roadmap](../ROADMAP.md): choose a contribution with a clear acceptance test.

The [app guide](../../apps/strathvision/README.md) contains setup and platform commands; the [interface contract](../INTERFACES.md) defines data formats. Historical phase completion in the handoff log means implementation milestones, not complete device or coaching validation.
